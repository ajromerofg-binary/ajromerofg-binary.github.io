Sobre mí

Soy Antonio José Romero Fernández-Giro, conocido en el ámbito técnico como Tony_ZeroD. Soy analista de ciberseguridad junior, orientado a SOC / Blue Team (el equipo que vigila y defiende los sistemas de una empresa). Tengo un Máster en Ciberseguridad & IA y el Técnico Superior en Desarrollo de Aplicaciones Web, con prácticas como desarrollador full-stack en Zaitec Innova.

Llevo más de 10 años en turnos 24x7 vigilando instalaciones críticas, detectando incidencias, avisando a tiempo y redactando informes. Busco un puesto junior donde crecer junto a un equipo técnico, aportando capacidad de análisis, disciplina en turnos rotativos y ganas de aprender.

HERRAMIENTA DE AUDITORÍA · OWASP TOP 10

WebScan Pro v2.0 — Analizador de Seguridad Web

Programa que revisa automáticamente si una página web tiene fallos de seguridad que un atacante podría aprovechar, siguiendo el OWASP Top 10 (la lista de los riesgos web más comunes). Al terminar genera tres informes: uno para dirección, uno técnico para el equipo de IT y uno interactivo en web, con una puntuación de riesgo de 0 a 100.

12 comprobaciones independientes (inyección SQL, XSS, SSRF y otras)
Prueba formularios, peticiones web y cabeceras
3 informes automáticos por análisis: ejecutivo, técnico y web
Detecta el gestor de contenidos (CMS) y las plantillas que usa la web

HERRAMIENTA OFENSIVA · ACTIVE DIRECTORY

ADReaper — AD Offensive Auditing Tool

Herramienta que audita la seguridad de Active Directory (el sistema que muchas empresas usan para gestionar usuarios y permisos de sus equipos Windows). Simula los pasos de un atacante para comprobar si podría llegar a controlar el dominio y genera un informe HTML con todo lo encontrado, para que la empresa pueda corregirlo.

Detecta contraseñas débiles en cuentas de servicio (Kerberoasting, AS-REP Roasting)
Revisa permisos mal configurados en cuentas y grupos (ACLs)
Muestra el camino que seguiría un atacante hasta ser administrador del dominio
Informe HTML por sesión e instalación automática de dependencias

HERRAMIENTA OFENSIVA · PIVOTING DE RED · POST-EXPLOTACIÓN

Kangaroo — Network Pivoting Automation

Herramienta para pruebas de seguridad autorizadas. Cuando un equipo de la red ya ha sido comprometido durante una auditoría, permite explorar desde él el resto de la red interna. Convierte varios pasos manuales en un solo comando.

Fase 0 — Reconocimiento: escanea la red interna desde el equipo comprometido
Fase 1 — Pivote: enruta el tráfico a través de ese equipo
Fase 2 — Proxy: abre un túnel local para usar otras herramientas
Fase 3 — Salida: genera los archivos de configuración listos para usar

HERRAMIENTA DEFENSIVA · CREDENTIAL HUNTING · BLUE TEAM / OSINT

Ghosttag — Credential & Metadata Hunter

Programa que rastrea una web o un conjunto de archivos en busca de información sensible expuesta por error: contraseñas, claves de acceso, direcciones internas y datos ocultos en documentos. Sirve para detectar fugas antes de que las encuentre un atacante. Entrega un informe en TXT o JSON.

53 patrones de búsqueda clasificados por gravedad (crítica, alta y media)
Analiza webs, PDF, Word, Excel, imágenes y bases de datos
Reconoce claves de servicios conocidos (Google, AWS, Stripe, GitHub)
Rastrea la web hasta 5 niveles de profundidad y exporta el resultado
